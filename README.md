# cyrus-sandbox-two

## About

This is a sandbox repository used to test Kittu's multi-repository routing. It has no real functionality of its own; it exists so that Kittu can be exercised against a team with several repositories (team CYR) and verified to route tasks to the correct one. Changes here are typically throwaway, made as part of routing checks (see PLAN.md A24 in ugudlado/kittu).

Run `npm test`.

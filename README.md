# cyrus-sandbox-two

## About

This is a sandbox repository used to test Kittu's multi-repository routing. It has no production purpose; its sole function is to verify that tasks addressed to the Cyrus Sandbox team's repositories are routed to the correct repo.

Second throwaway app that self-hosted Cyrus may change during multi-repo testing (PLAN.md A24 in ugudlado/kittu). Run `npm test`.
